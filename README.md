# My Favorite Series: Stranger Things

![Stranger Things Poster](https://upload.wikimedia.org/wikipedia/en/3/38/Stranger_Things_logo.png)

## 🎬 Overview
*Stranger Things* is a science fiction horror drama set in the 1980s.  
It follows a group of kids as they encounter mysterious supernatural events in the town of Hawkins, Indiana.
